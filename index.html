AI-ASSISTED MARKET ANALYSISAPI / IN DEVELOPMENT

Kairox formerly TradeSight AI

A market-analysis tool combining chart interpretation, model reasoning and market context in one workflow.

PythonFastAPIGeminiKimi K2Llama 3.3
The problem

Market research can be fragmented across charts, news and separate tools. Kairox explores a more structured analysis flow.

Approach

The API accepts chart images for analysis, combines vision output with reasoning and news sentiment, and exposes market-data endpoints. Binance data is supported; forex data can use Twelve Data.

Engineering notes

FastAPI service, model-provider integrations, market-data caching and automated tests. The project README documents the API and its educational-use limitations.

JavaScriptOpenRouterLocal modelsAI evaluation
The idea

Make it easier to compare model behaviour and experiment with different inference setups without committing to a single provider.

What it includes
